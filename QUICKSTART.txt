## 🐛 If Something Breaks

**Console says error?**
```javascript
// Clear and restart
Storage.clearAllData()
location.reload()
```

**Page looks weird?**
```javascript
// Reset styles
localStorage.clear()
location.reload()
```

**Data not saving?**
```javascript
// Check storage
Storage.logStorageInfo()
```
